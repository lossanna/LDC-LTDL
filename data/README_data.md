# README for `data/`

Created: 2025-12-04  
Updated: 2026-01-09

Some subfolders contain their own README.

## Directory
- `data-wrangling-intermediate/`
    - Subfolder contains own README.
- `from-Ron/`
    - Cleaned data that Ron used for analysis; not pushed to GitHub.
    - Files:
        - `allDATA_trts_20250910.RDS`
        - `Ron-data_columns.xlsx`
- `GIS-exports/`
    - CSVs exported from Arc GIS Pro (products of geoprocessing); not pushed to GitHub.
    - See [Google Doc notes](https://docs.google.com/document/d/1gshsoIPIgJ5tUT7jBK2LmrB_ZmTPzvl8P9q5xpuQqKA/edit?tab=t.k3zdxibjwain) for more information.
- `LDC-points/`
    - Shapefiles of the LDC points, created from `scripts/03_LDC-to-shapefile.R`.
    - Not pushed to GitHub.
- `raw/`
    - Raw data; most files not pushed to GitHub.
    - Subfolder contains own README.
- `versions-from-R/`
    - Versions of any data cleaned in R and read back into ArcGIS Pro for analysis (such as LTDL treatment info table or LDC points); not pushed to GitHub.
    - README located in `data/` folder to track version changes.
