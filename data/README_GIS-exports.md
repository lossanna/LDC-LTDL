# README for `data/GIS-exports/`

Created: 2025-12-11  
Updated: 2025-12-11

Contains files exported from ArcGIS Pro that were made from geoprocessing.

## Notes
- This file is kept in the `data/` folder and not the `data/GIS-exports/` folder because the latter is not pushed to GitHub, but I would like to have version control for the README, which will document all the tables produced from geoprocessing in ArcGIS Pro and written out for data cleaning/exploration in R.
- Numbers at the beginning of the file name refer to the corresponding ArcGIS Pro map.
- Exported tables include the table in CSV form, as well as an associated XML file. Only the CSVs are listed here for brevity.
